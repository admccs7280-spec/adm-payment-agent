# Seguridad operativa

- No añadas claves bancarias, claves API, sesiones, números completos de cuentas ni capturas al repositorio.
- Las pruebas de este repositorio usan únicamente ejecutores simulados; no deben tocar teléfonos, emuladores ni red.
- Un adaptador real no puede reintentar solo un pago cuyo resultado sea incierto.
- Cualquier cambio de un adaptador se prueba primero en una copia de laboratorio y se distribuye por versión etiquetada.
